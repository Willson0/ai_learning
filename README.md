## О проекте

**AI Learning Platform** — это образовательная платформа, объединяющая Telegram-бота и WebApp-интерфейс для подготовки школьников к экзаменам и контрольным работам.

Проект создан для прохождения пробников, пробных тестирований, подготовки по школьным темам, общения с нейросетью и получения помощи через чат поддержки.  
Система помогает ученикам эффективно готовиться к **ВПР, ОГЭ и ЕГЭ**, совмещая удобство Telegram и полноценный веб-интерфейс.

---

## Основной функционал

- Авторизация через Telegram
- Подготовка к ВПР, ОГЭ и ЕГЭ
- Прохождение пробных тестирований
- Решение тестов и заданий по темам
- Чат с нейросетью по школьной программе
- Чат с поддержкой
- Веб-интерфейс для удобной работы с материалами
- Адаптивная верстка для мобильных устройств
- Интеграция Telegram Bot + WebApp

## Запуск проекта

Проект запускается с помощью Docker.

### Требования
- Docker
- Docker Compose

### Установка и запуск

```bash
docker-compose up --build
```


После запуска приложение будет доступно по адресу, указанному в конфигурации Docker.
